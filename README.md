# DARKSKY Hookah Lounge — меню с заказом к столу

Гость сканирует QR-код на столе → открывается меню, привязанное к его столу → собирает заказ, проверяет его на экране «Оформить заказ» и отправляет → бот присылает заказ **в личку каждому официанту на смене** с кнопкой «✋ Взять заказ»; кто первым нажал — того и заказ, у остальных сообщение меняется на «Заказ взял(а) Ана». Не взяли за 3 минуты — бот напоминает (до 3 раз, `ORDER_REMIND_MIN` / `ORDER_REMIND_TIMES`). Если заказ правит кто-то другой, взявшему приходит личное сообщение со списком изменений. Группа в Telegram (`TELEGRAM_CHAT_ID`, необязательно) — лента для владельцев: те же заказы со статусом, без кнопок. Гость видит статус и актуальный состав у себя в телефоне.

- **Меню для гостя** — `/` (только просмотр) и `/t/<код стола>` (с заказом). 10 языков, поиск, корзина, скидка −15% за наличные/крипто.
- **Приложение персонала** — `/staff`: официанты открывают его из бота как мини-приложение Telegram и входят под своим именем автоматически (бот проверяет аккаунт; новый официант ждёт одобрения в админке → «Персонал»). Смена — кнопкой в приложении или командой `/smena` боту (забытая закрывается через 14 ч). Новые / Одобрены / Поданы, звук и уведомление о новом заказе, карточка заказа с правкой (кол-во, удалить, добавить блюдо). Общий планшет у бара входит по PIN (`STAFF_PIN`) и при «Одобрено» выбирает официанта на смене.
- **Персонал** в админке: заявки (одобрить, переименовать, заблокировать), кто сейчас на смене, история смен и часы. Статистика официантов — по их аккаунтам: заказы, выручка, скорость одобрения, часы смен, заказов в час.
- **Админка** — `/admin` (вход по паролю):
  - **Меню**: добавить / изменить / удалить блюдо, фото, цены и варианты, описания на ES / EN / RU, вкус, крепость, «хит», «новинка», порядок в категории;
  - **Фото блюда**: при загрузке фон вырезается прямо в браузере (модель BiRefNet, MIT, ~115 МБ скачивается один раз и кэшируется), блюдо встаёт на дымный фон, как остальные; можно оставить оригинал;
  - **Языки**: все тексты (название, описание, варианты, акции, правила) вводятся вручную на каждом из 10 языков. Панель языков сверху формы переключает все поля сразу, показывает заполненность каждого языка и прыгает к следующему незаполненному (Alt+← / Alt+→); под полем — испанский образец. Пустой язык гость видит на английском или испанском;
  - **Контент**: названия и подписи плиток главной, строка «Приготовление 10–15 мин», категории (переименовать, скрыть вместе с блюдами, порядок вкладок), акции (добавить, удалить, часы действия), правила;
  - **Стоп-лист**: переключатель «В наличии» — блюдо сразу пропадает из меню гостей;
  - **Столы и QR**: добавить столы, выключить стол, выпустить новую ссылку, распечатать все QR-коды на листах A4;
  - **Статистика**: выручка, заказы, средний чек и позиции с сравнением к прошлому периоду (сегодня / 7 / 30 / 90 дней, день = смена 06:00–06:00), выручка по дням, загрузка по часам и дням недели, топ блюд и доли категорий, столы, скорость обслуживания, официанты, оплата наличными/крипто, скидки, изменённые заказы;
  - **Заказы**: история заказов со статусами;
  - **Telegram**: проверка и подключение бота.

## Запуск (один раз, ~20 минут)

Нужны три бесплатных аккаунта: **Supabase** (база данных), **Vercel** (хостинг сайта), **Telegram-бот**.

### 1. База данных — Supabase
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project** (регион: South America (São Paulo)). Придумайте и сохраните пароль базы.
2. В проекте нажмите **Connect** → вкладка **Connection string** → **Transaction pooler**. Скопируйте строку и подставьте в неё пароль вместо `[YOUR-PASSWORD]`. Это `DATABASE_URL`.

### 2. Бот — Telegram
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите **токен**. Это `TELEGRAM_BOT_TOKEN`.
2. Создайте группу для официантов и добавьте туда бота. Напишите в группе любое сообщение.

### 3. Сайт — Vercel
1. Зарегистрируйтесь на [vercel.com](https://vercel.com) через GitHub → **Add New → Project** → выберите репозиторий `dark-sky-`.
2. В **Environment Variables** добавьте:
   | Переменная | Значение |
   | --- | --- |
   | `DATABASE_URL` | строка из Supabase |
   | `ADMIN_PASSWORD` | пароль для входа в админку |
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `STAFF_PIN` | PIN для страницы заказов `/staff` (6+ цифр) |
3. Нажмите **Deploy**. При первой сборке база заполнится сама: всё текущее меню и 20 столов.

### 4. Подключить бота
1. Откройте `https://<ваш-сайт>.vercel.app/admin` → войдите → вкладка **Telegram** → **Найти группу** — появится номер группы (вида `-100…`). В Vercel добавьте переменную `TELEGRAM_CHAT_ID` с этим номером → **Redeploy**.
2. Там же → **Подключить вебхук**: после этого работают кнопки в группе и команды `/start`, `/smena` (номер группы можно узнать и командой `/id`).
3. В @BotFather → `/mybots` → бот → **Bot Settings → Configure Mini App → Enable** → адрес `https://<ваш-сайт>/staff`. Тогда «Открыть заказ» и кнопка в чате с ботом открывают приложение прямо в Telegram.
4. **Отправить тест в группу** — сообщение пришло, всё готово.
5. Каждый официант пишет боту `/start` → в админке **Персонал** → **Одобрить**.

### 5. QR-коды
Админка → **Столы и QR** → добавьте недостающие столы → **Распечатать QR-коды**. Если подключите свой домен, сначала укажите его в переменной `SITE_URL`, а потом печатайте — QR ведут на адрес сайта.

## Свой сервер (Hetzner или любой VPS с Docker)

Сайт, база и https на одном сервере: `docker-compose.yml` (приложение, Postgres, Caddy). Сертификат Caddy получает сам.

1. Сервер Ubuntu 24.04 (например Hetzner CAX11, ~€5/мес), Docker: `curl -fsSL https://get.docker.com | sh`.
2. Код: `git clone` этого репозитория в `/opt/darksky`.
3. Секреты: `cp deploy/env.example deploy/.env` и заполнить. Без домена `SITE_HOST=<IP-через-дефисы>.sslip.io` (например `203-0-113-10.sslip.io`), с доменом — сам домен (A-запись на IP сервера).
4. Запуск и обновление: `docker compose --env-file deploy/.env up -d --build`. При старте приложение само создаёт таблицы и заполняет пустую базу меню и 20 столами.
5. Telegram: админка → Telegram → «Найти группу» → `TELEGRAM_CHAT_ID` в `deploy/.env` → снова шаг 4 → «Подключить вебхук»; мини-приложение в @BotFather с адресом `https://<SITE_HOST>/staff`.

Резервная копия базы: `docker compose --env-file deploy/.env exec db pg_dump -U darksky darksky > backup.sql`.

## Полезно знать
- Цены в заказе всегда пересчитываются на сервере по базе — подделать цену с телефона нельзя.
- Ссылка стола содержит секретный код: номер стола в адресе подменить нельзя. Если QR-код украли или испортили — «Новая ссылка» в админке, старый перестанет работать.
- С одного стола — не больше 5 заказов за 2 минуты (защита от спама).
- Если Telegram недоступен, заказ всё равно принимается и виден на странице `/staff` (ошибка пишется в лог сервера).
- Акции (Business Hookah, 2-й/3-й кальян) в сумме заказа не считаются — их применяет официант при расчёте. Автоматически считается только −15% за наличные/крипто.
- Время в сообщениях — по Буэнос-Айресу; другой часовой пояс: переменная `VENUE_TIMEZONE`.

## Для разработчика

```bash
npm install
cp .env.example .env.local        # заполнить
npm run db:setup                  # схема + меню + столы (идемпотентно); также запускается перед каждым build
npm run dev
```

### Локальная база в Docker
```bash
docker run -d --name darksky-pg --restart unless-stopped -e POSTGRES_USER=darksky -e POSTGRES_PASSWORD=<пароль> -e POSTGRES_DB=darksky -p 127.0.0.1:5435:5432 -v darksky-pg:/var/lib/postgresql/data postgres:17-alpine
```
В `.env.local`: `DATABASE_URL=postgres://darksky:<пароль>@localhost:5435/darksky`, `ADMIN_PASSWORD`, `STAFF_PIN`; затем `npm run db:setup`.

Тестовые заказы для статистики (только для локальной базы, помечены `lang = 'demo'`):
```bash
node --env-file=.env.local scripts/seed-demo-orders.mjs            # ~400 заказов за 60 дней
node --env-file=.env.local scripts/seed-demo-orders.mjs --clear    # удалить только тестовые
```

Без `DATABASE_URL` меню работает на встроенных данных, а заказы хранятся в памяти сервера до перезапуска: столы открываются по `/t/demo-1` … `/t/demo-20`, страница персонала — `/staff` (нужен только `STAFF_PIN` в `.env.local`).
